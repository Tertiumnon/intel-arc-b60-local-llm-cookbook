# Recommendations

Use `bun run switch:coding` to choose the model, approach, and context. **Keep Strata Flash-Next Coder IQ1_M as the default for Kyra and Pi**, as previously chosen. The November 27–28 version 3 sweep now provides comparable complex-task results for 12 configurations at 57,344 allocated context and roughly 41K actual input tokens. It is unfinished, with one sample per task: these results guide candidates, not a definitive model ranking. See the [partial sweep](./results.md#partial-57k-complex-sweep-november-2728-2026) for settings, input lengths, and failures.

Qwen3.8 Q4_K_XL without MTP passed four tasks but truncated TTL at 8,192 output tokens. Qwen3.6 IQ4_XS passed four with MTP on and three with it off; the remaining answers were truncated, not failed quality checks. Neither is established as a better choice by this run. IQ3_M without MTP passed 4/5 and took longer than the MTP run, but one sample does not establish a general MTP quality benefit. Strata IQ2_XS scored 3/5 in 497.5 s, with the same failing tasks as Coder IQ1_M; this is insufficient reason to replace the chosen default.

Dirk's latest saved version 3 run is still marked `running` on its first task, with no answer or verdict; its earlier partial 57K results remain historical evidence only. Greatjedi Arc-tuned Pi, ThinkingCap, and Tiel-Coder have no results in this sweep snapshot. Tiel-Coder's earlier 49.3 tok/s short-prompt result is not a quality score; the smaller Greatjedi IQ3_S was previously rejected after a simple commit-request failure.

Context includes input and output. This sweep's roughly 41K inputs plus an 8,192-token output cap fit within 57,344; it does not demonstrate 49K-input or full-window reliability. For coding evaluations use at least 49,152 allocated tokens, record actual input lengths, and check generated code, especially cache expiry, expression validation, and dependency names. A 57K allocation cannot reserve a full 4K output after a 54.5K input.
